# yuripinaev-site

Статический многостраничный сайт для GitHub Pages.

## Структура

- `index.html`
- `korporativy.html`
- `svadby.html`
- `yubilei.html`
- `muzyka.html`
- `otzyvy.html`
- `contacts.html`
- `assets/css/style.css`
- `assets/js/main.js`
- `assets/images/`
- `assets/video/`

Все пути в HTML относительные, сайт готовится к публикации в GitHub Pages по адресу `/yuripinaev-site/`.

## Текущий этап

Созданы базовая структура, общий layout, навигация, footer, адаптивные стили, мягкие анимации и пустые секции-плейсхолдеры для будущих фото и видео.
